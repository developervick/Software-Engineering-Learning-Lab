# 03 — Design patterns

**Goal:** practice each pattern **alone** — build it, then argue **when NOT to use it**.

A pattern is a **named solution to a recurring problem**, not a goal. The point of practicing
them in isolation is to build the judgment to *not* reach for them when they don't fit.

**Every pattern file ends with "When NOT to use it."** If you can't answer that, you don't
understand the pattern yet — you've just memorized it.

**Move on to [`04-lld-topics/`](../04-lld-topics/) when:** for any pattern you can (a) build
it from memory, (b) name the real problem it solves, and (c) name a case where a simpler
solution is better.
