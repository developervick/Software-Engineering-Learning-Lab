# Curriculum — learn the concepts, one at a time

The **concept-first** part of the lab. Before you build solutions (challenges), you learn
and drill each idea **in isolation** and pass a **gate** for it.

## The path

```
01-fundamentals/ → 02-solid/ → 03-design-patterns/ → 04-lld-topics/
                            ↓
        challenges/   (you COMBINE several concepts into a solution)
```

**Rule:** do not start a challenge until the concept gates it depends on are met.

## How a concept works

Each concept file contains: **Goal · Drill (do alone) · Done-when checklist (the gate) ·
Reflection · short Theory & resources.**

- Do the drill **yourself first**. No AI.
- The file **never** contains the solution.
- Stuck? Ask for hint → direction → review → partial → full (see
  [`../docs/how-to-use-this-repo.md`](../docs/how-to-use-this-repo.md)).
- When the gate is met, mark it in [`../progress/concept-tracker.md`](../progress/concept-tracker.md).

## Why drill in isolation first

You can't reliably **combine** concepts (e.g. Strategy + OCP + DI) if you've never built
each one alone. Isolation exposes exactly which one you don't actually understand yet.
