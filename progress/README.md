## How to use this

2. When its gate is met, update its row in [`concept-tracker.md`](concept-tracker.md).
3. Update the matching row in [`capabilities.md`](capabilities.md).
4. Anything you're weak on, or want to revisit → [`gaps.md`](gaps.md).
5. Fill the **Dashboard** above so future-you always knows the next step.
