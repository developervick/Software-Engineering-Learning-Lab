# Chapter 1 — Programming & design fundamentals

**Goal:** model a small domain correctly and put behavior in the right place.

**Concepts:** classes & responsibilities · encapsulation · composition · basic interfaces ·
validation · error handling · invariants · small refactoring.

**You practice:** restating vague requirements, listing assumptions + invariants, and
producing a small design whose pieces each have one clear job.
