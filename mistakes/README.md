# Mistakes

A log of recurring mistakes, so **patterns** become visible. Rule: log a pattern the
**third** time it repeats — not every time.

| File | Tracks |
|------|--------|
| [`design-mistakes.md`](design-mistakes.md) | Responsibility, coupling, abstraction, over/under-engineering |
| [`implementation-mistakes.md`](implementation-mistakes.md) | Correctness, edge cases, error handling, style |
| [`testing-mistakes.md`](testing-mistakes.md) | Missing cases, brittle tests, testing the wrong thing |
| [`reasoning-mistakes.md`](reasoning-mistakes.md) | Skipping requirements, assuming, jumping to patterns |
